# Planar Five

## Установка и запуск в Windows

1. Установите **Python 3.12** с [python.org](https://www.python.org/downloads/).
   При установке включите добавление Python в PATH или установите Python Launcher.
2. Сохраните весь проект в постоянной папке (не копируйте один `setup.bat` на
   рабочий стол). Запустите двойным щелчком `setup.bat` из папки проекта.
3. Дождитесь установки зависимостей: нужны подключение к интернету и свободное
   место, установка может занять несколько минут. Установщик создаст `.venv`
   внутри проекта и ярлыки **Planar Five** и **Planar Five Training** на рабочем
   столе текущего пользователя.
4. Запускайте программу нужным ярлыком. Не запускайте основную программу и
   мастер обучения одновременно: они используют одни и те же камеры и робот.

Если проект перенесён в другую папку, удалите `.venv` и снова запустите
`setup.bat`: виртуальное окружение и ярлыки привязаны к расположению проекта.
Если установка завершилась ошибкой, прочитайте сообщение в окне и повторите
запуск установщика. При отсутствии ярлыков можно запускать `run_app.bat` и
`run_training.bat` непосредственно из папки проекта.

Подробнее о мастере обучения, в том числе о режиме без контроллера и мерах
безопасности, см. [project/training/README.md](project/training/README.md).
