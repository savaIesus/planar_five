# Мастер обучающих кадров для planar_five

В Windows можно запустить `setup.bat` из корня проекта и затем использовать
ярлык **Planar Five Training** на рабочем столе (см. [инструкцию по установке](../../README.md)).
Мастер запускается с автоматическим управлением роботом.

Ручной запуск из корня репозитория на компьютере станции (Python 3.12 или новее):

```text
pip install -r requirements.txt
python -m project.training --open-browser
```

Остановите основное приложение: оно и мастер не должны одновременно управлять
роботом и камерами. По умолчанию веб-интерфейс доступен только на этом
компьютере. При необходимости укажите `--serial-port COM3` (иначе используется
поиск USB-SERIAL и параметры из `project.station.connection`). Для ручного
позиционирования без контроллера используйте `--motion off`. При этом оператор
сам устанавливает робот у каждого корпуса до нажатия «Новая деталь».

При работе с роботом первая кнопка «Новая деталь» запускает G28 и переход к
координатам из `cell_coordinates.json` через функции основного проекта.
Последующие нажатия перемещают робот по сетке 10×10: 18,7 по X, 19,2 по Y,
строки проходят в противоположных направлениях. После сотой ячейки движения
больше не выполняются. Новая сессия начинает маршрут заново с калибровки.
«Завершить деталь» только сохраняет разметку; между камерами робот не движется.
Номер строки/колонки и координаты сохраняются в данных детали. Камеры
`CAMERA_0`–`CAMERA_4` соответствуют индексам OpenCV основного алгоритма;
камера 4 — центральная, 1 и 2 — дальняя и ближняя, 0 и 3 — боковые.
Выбранные кадры снимаются и размечаются последовательно, не одновременно.

При ошибке перемещения повторные команды блокируются до перезапуска мастера:
сначала проверьте фактическое положение и состояние установки. Сессии не
восстанавливаются после перезапуска, но сохранённые файлы остаются на диске.
Автоматический перенос на следующую ячейку не происходит, пока оператор не
начнёт новую деталь. Исходники, разметка и YOLO-экспорт находятся в
`training_datasets` (или в каталоге, указанном через `--root`).

**Перед работой на оборудовании** проверьте координаты первой ячейки,
направления и безопасность полного маршрута. Перемещения используют штатную
функцию проекта: она рассчитывает время по скорости и не подтверждает фактическое
достижение точки контроллером. Поэтому необходим контроль оператором; тесты с
имитацией устройств не заменяют проверку на станции. Не открывайте веб-сервер
во внешнюю сеть: авторизация в мастере отсутствует.
